# 투상도 작도 연구실

중학교 2학년 기술·가정 수업을 위한 등각투상도·사투상도 학습 및 자유 작도 정적 웹앱입니다. 원본의 카드 디자인, 4개 연습문제, 5단계 학습 흐름을 유지했습니다.

## 실행

Node.js 18 이상, Python 3이 필요합니다. 앱 자체는 외부 패키지, API, 로그인 없이 동작합니다.

```sh
npm ci
npm start
```

로컬 포트는 4173입니다. ES 모듈을 사용하므로 HTML을 파일로 직접 열지 말고 HTTP 서버를 사용합니다.

## 브라우저 검증

```sh
# 시스템 Chromium이 /usr/bin/chromium에 있는 경우
npm test
# 다른 Chromium 실행 파일을 사용할 경우
CHROMIUM_PATH=/path/to/chromium npm test
```

Playwright 설치 브라우저를 사용하는 환경에서는 `npx playwright install chromium`으로 브라우저를 준비한 후 해당 실행 파일을 `CHROMIUM_PATH`로 지정합니다. 테스트는 자체 로컬 서버를 열고 종료합니다. `TEST_URL=https://실제배포주소 npm test`로 같은 테스트를 배포본에도 실행할 수 있습니다. 결과와 화면 캡처는 `test-results/`에 저장됩니다.

## 교육 규칙

- 한 칸은 1단위입니다. 등각투상도의 수직 위·좌우 아래 30° 축은 서로 120°이며 동일 축척입니다.
- 사투상도는 정면 실제 치수, 오른쪽 위 45° 깊이, 깊이 길이 1/2의 캐비닛 방식입니다. 깊이 2단위이면 도면 선 길이는 1단위이며 수평·수직 이동량은 각각 1/√2단위입니다.
- 실선은 보이는 모서리, 파선은 숨은선입니다. 기준축은 가는 일점쇄선, 작도 보조선은 가는 실선으로 구분합니다.
- 최종 답안은 문제 안내에 따라 보이는 모서리 9개만 제출합니다. 이 앱은 제도 규격 전체를 평가하는 도구가 아닙니다.
- 자동 채점은 동일 투상 방향의 직육면체를 평가합니다. 위치 이동과 선의 입력 순서·시작 방향은 자유입니다. 회전·반전·확대·축소, 분할 모서리, 복합 입체는 정답으로 인정하지 않습니다.
- 실제 입력은 격자·일반 45° 깊이 눈금/기존 끝점에 스냅되며 사투상도 깊이는 0.5단위 선 길이로 스냅됩니다. 정답 꼭짓점을 스냅 후보로 사용하지 않습니다.
- 드래그 작도는 마우스·터치를 지원합니다. 키보드만으로 작도하는 기능은 제공하지 않습니다.

## Vercel 배포

GitHub 저장소 `gpals8956-dot/technology`의 `main`을 Vercel 프로젝트로 가져옵니다. Framework Preset은 **Other**, Root Directory는 저장소 루트이며, 빌드 명령은 없습니다. `vercel.json`에 정적 배포 설정과 보안 응답 헤더가 들어 있습니다.

인증된 Vercel CLI를 사용할 때는 저장소 루트에서 `vercel --prod`로 배포합니다. Vercel 인증 토큰은 앱에 필요하지 않으며 배포 도구만 사용합니다. 토큰을 저장소·브라우저 코드·로그에 넣지 않습니다.

공개 HTTPS 주소 생성 및 배포본 테스트는 Vercel 권한과 네트워크 허용이 준비된 뒤 수행해야 합니다. 로컬 테스트 통과가 배포 성공을 의미하지 않습니다.
